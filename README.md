# 📦 Tích hợp: Bán hàng - Quản lý kho

---

## 📌 Giới thiệu Dự án

Dự án **Tích hợp: Bán hàng - Quản lý kho** là một hệ thống ứng dụng quản lý kho và bán hàng, với khả năng xử lý dữ liệu nhập kho, xuất kho và quản lý thông tin đơn hàng. Dự án này tích hợp các chức năng **import**, **export** dữ liệu từ file CSV và quản lý các lỗi trong quá trình nhập liệu. Các tính năng chính của hệ thống bao gồm:

- **Nhập dữ liệu từ file CSV**: Hỗ trợ người dùng nhập dữ liệu hàng hóa vào hệ thống.
- **Xuất dữ liệu ra file CSV**: Xuất các báo cáo và dữ liệu kho dưới dạng CSV.
- **Quản lý lỗi trong quá trình nhập dữ liệu**: Ghi lại các lỗi phát sinh trong quá trình nhập và xuất dữ liệu.
- **Giao diện người dùng trực quan**: Giao diện web dễ sử dụng với khả năng tương tác trực tiếp.
